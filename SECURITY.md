# Security Policy

## Supported versions

Only the latest Clodex release receives security fixes.

## Reporting a vulnerability

Report undisclosed vulnerabilities through [GitHub private vulnerability
reporting](https://github.com/Aotricx/Clodex/security/advisories/new). Do not open
a public issue for an undisclosed vulnerability.

Include the affected version, reproduction steps, expected impact, and any
suggested remediation.
